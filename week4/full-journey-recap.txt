1. What is the difference between Git and Docker?

Git helps you save and manage your project code.
Docker helps you run the project the same way on any machine.


2. What is the difference between Docker and EC2?

Docker packages my Expense Tracker app with its environment.
EC2 provides the cloud server that hosts the app online.


3. What does systemd do and why did you need it?

Automatically start the application when the server boots
Keep the app running continuously
Restart the app if it crashes
Manage and monitor the application service easily



4. What is the full deployment workflow from code to live app?


1. Write the application code locally

2. Use Git to track and push code to GitHub

3. Create a Dockerfile for the app

4. Build the Docker image

5. Push the image to Docker Hub

6. Launch an Amazon EC2 server

7. SSH into the server

8. Install Docker on the server

9. Pull the Docker image from Docker Hub

10. Run the container on the EC2 server

11. Configure systemd to keep the app running

12. Open the server IP in the browser to access the live application







5. What are the 3 most important things you learned in 4 weeks?



1. Cloud Deployment

How to deploy applications to a live cloud server using Amazon Web Services EC2.

2. Docker Containerization

How to package applications with Docker so they run consistently on different systems.

3. Linux Server Management

How to manage servers using SSH, systemctl, logs, ports, and Linux commands.
